# V4 安全与隐私威胁清单

## 适用边界

本清单覆盖当前单实例 RAG 应用的 API、上传文件、应用内账号、知识库数据和浏览器入口。
它用于验证代码级安全边界，不代表已接入企业 DLP、外部 WAF、恶意软件扫描或正式环境
安全运营。

## 已缓解风险

| 风险 | 当前控制 | 自动化证据 |
| --- | --- | --- |
| 未认证或跨知识库访问 | 业务 API 默认认证，服务端按角色和知识库授权 | `test_auth.py` |
| 路径穿越与危险文件名 | 拒绝路径、控制字符、隐藏名和超长文件名 | `test_security.py` |
| 伪造或二进制上传 | 扩展名、MIME、PDF 标识和文本二进制特征校验 | `test_security.py` |
| 过大请求耗尽内存 | 请求体上限和独立上传上限 | `test_security.py` |
| 登录暴力尝试 | 按客户端与用户名执行滑动窗口限流 | `test_security.py` |
| 模型及索引资源耗尽 | 上传和问答按用户限流，并设置进程内并发上限 | `test_security.py` |
| 凭据或内部异常泄漏 | 参数错误不回显输入，未知异常不返回异常正文 | `test_security.py` |
| 浏览器缓存或嵌入敏感页面 | no-store、CSP、禁止 iframe、MIME 嗅探等响应头 | `test_security.py`、容器 CI |
| 跨域配置过宽 | 禁止通配来源；生产模式只接受 HTTPS 来源 | `test_security.py` |
| 原始上传文件被同机其他用户读取 | 新写入目录为 0700，文件为 0600 | `test_security.py` |
| 无界列表扩大响应 | 列表接口统一限制 offset 和 limit，单页最多 100 条 | `test_security.py` |

## 数据最小化与删除边界

- 环境密钥不进入仓库、响应、会话存储或错误详情。
- 认证存储只保存密码摘要和会话令牌摘要。
- 问答历史保留业务功能所需的问题、答案和来源快照，不保存完整 Prompt 或供应商原始响应。
- 删除文档时同步删除向量和对应原始上传文件；删除会话时同步删除其回答记录。
- 本阶段不新增隐式软删除或隐藏保留副本。备份保留、恢复点和生命周期由 #61 单独实施。

## 已知限制与延期项

- 进程内限流不跨实例共享，服务重启后计数清空；多实例部署需在网关或共享存储层补充。
- 文件校验不是恶意软件扫描，不应上传来源不可信的主动内容。
- TLS、HSTS、外部 WAF、长期日志分析和告警依赖最终部署平台，本阶段不部署 Render。
- 结构化日志、指标与持久化审计属于 #60；备份恢复与数据生命周期属于 #61。
- 系统、成员和审计页面属于 #62；版本发布与回滚属于 #63。
