# V5-7｜多数据源接入与同步管理（固定 8 步）

## 范围

| 步骤 | 页面范围 | 核心能力 |
| --- | --- | --- |
| 1 | 数据源配置 | Connector 协议、配置校验、连通性测试 |
| 2 | S3 配置 | S3/MinIO、Prefix、ETag、凭据环境变量 |
| 3 | 同步状态 | Schema V12、Sync Run、阶段、计数、游标 |
| 4 | 操作入口 | 新建、编辑、测试、同步、停用、删除、重试 |
| 5 | 治理映射 | 默认分类、Metadata、外部资源 ID、ACL 继承 |
| 6 | 知识库详情 | 紧凑型数据源 Table、局部进度、同步记录 |
| 7 | 异常运维 | 并发防重、删除熔断、失败原因、自动刷新 |
| 8 | 轻量验收 | 专项 Pytest、Ruff、Vitest、ESLint、TypeScript |

## 边界

- 已实现真实 S3 兼容对象存储连接器；本地目录作为协议参考实现。
- 增量同步以远端对象清单和版本标识计算差异；游标保存清单指纹，用于追踪同步批次。
- 凭据只从环境变量读取，不进入数据库、接口或审计 payload。
- 外部删除先软删除并退出检索；大批量删除由熔断器中止。
- 单对象索引失败可在下一次同步重试，不回滚本批已成功对象。
- 本阶段不实现 Web、数据库、Google Drive、Confluence 或 Notion 连接器。
