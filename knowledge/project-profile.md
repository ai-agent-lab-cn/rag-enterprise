# RongRAG Studio 项目资料

## 项目目标

RongRAG Studio 是一个面向个人项目资料的可解释问答系统。它解决的问题不是让模型记住更多内容，而是让每个回答都能追溯到用户上传的原始资料。项目适合作为求职作品集，展示从文档解析、检索到生成和评测的完整工程链路。

## 技术架构

后端使用 FastAPI，前端使用 React、TypeScript 和 Vite。Markdown、TXT 与 PDF 文档会被解析为带页码或段落编号的文本片段。本地中文 Embedding 模型把文本转为向量，ChromaDB 负责持久化存储和相似度召回。CrossEncoder 对候选片段进行精排，Gemini 根据精排后的证据生成带来源标签的答案。

## 可解释性

系统同时展示向量召回分数和 CrossEncoder 精排分数。答案下方列出文件名、页码或段落、chunk 编号和原文。接口还返回检索、精排、生成与总耗时，使用户可以判断时间花在了哪个阶段。

## 评测方法

项目使用人工编写的问题集记录每个问题对应的正确文档和段落。评测脚本计算 Recall@K 和 MRR，并比较纯向量排序与 CrossEncoder 精排后的结果。这样可以量化精排是否真的改善了候选顺序，而不是只凭主观感受判断效果。

## 隐私与边界

上传文件、ChromaDB 索引和 API 密钥只保存在本地且默认被 Git 忽略。公开演示资料不包含真实电话、邮箱、访问令牌或其他个人敏感信息。当检索资料不足时，Prompt 要求生成模型明确说明无法确定，不得编造答案。
