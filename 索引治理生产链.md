索引治理生产链：
                        Index Definition（索引定义）
                              │
                              │ Snapshot（生成配置快照）
                              ▼
                     Index Version（索引版本）
                              │
                              │ Building（构建）
                              ▼
                      Index Build（索引构建）
                              │
                   ┌──────────┴──────────┐
                   │                     │
            build_failed（构建失败）   success（构建成功）
                   │                     │
                   │                     ▼
                   │               Validate（验证）
                   │                     │
                   │      ┌──────────────┼──────────────┐
                   │      │              │              │
                   │      ▼              ▼              ▼
                   │  完整性校验       技术校验        检索质量校验
                   │
                   │  Document         Vector          Recall@5
                   │  coverage         Metadata        Recall@10
                   │  Chunk            ACL             MRR
                   │  consistency      Citation        nDCG@10
                   │  ACL consistency  Version
                   │
                   │  missing_document
                   │  orphan_chunk
                   │  duplicate_chunk
                   │
                   │                     │
                   │             ┌───────┴───────┐
                   │             │               │
                   │        failed（失败）     pass（通过）
                   │             │               │
                   │             ▼               ▼
                   │   validation_failed       ready
                   │       （验证失败）        （待发布）
                   │             │               │
                   │      ┌──────┼──────┐        │
                   │      │      │      │        │ Activate（激活）
                   │      ▼      ▼      ▼        │
                   │   查看报告 重新验证 重新构建 │
                   │             │      │        ▼
                   │             ▼      ▼      active
                   │        validating building （当前生效）
                   │                            │
                   │                            │ 下一版本激活
                   │                            ▼
                   │                         previous
                   │                       （上一生效版本）
                   │                            │
                   │                            │ Retire（退役）
                   │                            ▼
                   │                         retired
                   │                        （已退役）
                   │                            │
                   │                            │ Cleanup（清理）
                   │                            ▼
                   │                         cleaned
                   │                        （已清理）
                   │
                   └─ 构建失败处理：
                      查看构建日志 / 重试构建
状态名称建议最终统一成：
draft（草稿） → building（构建中） → validating（验证中） → ready（待发布） → active（当前生效） → previous（上一生效版本） → retired（已退役） → cleaned（已清理）
失败状态：
build_failed（构建失败）
validation_failed（验证失败）
